VolunteerHub Developer Portal

APIs for volunteer operations

Đây là trang developer portal đơn giản cho hệ backend VolunteerHub. Hệ thống được thiết kế theo mô hình microservices để quản lý sự kiện tình nguyện, đăng ký tham gia, tương tác cộng đồng, chat thời gian thực, thông báo và phân tích dữ liệu.

Use cases

Tích hợp nhanh cho frontend hoặc mobile

  • Khám phá sự kiện và tìm kiếm theo bộ lọc.
  • Đăng ký tham gia, duyệt participant và theo dõi trạng thái.
  • Check-in và xác nhận hoàn thành bằng QR.
  • Tạo bài viết cộng đồng, chat và nhận notification.
Tech stack
Spring Boot microservices
PostgreSQL, Redis, RabbitMQ
OAuth2 / JWT / Role-based access
Firebase Storage và Web Push

Core services

Authorization + User

Xử lý đăng nhập, cấp token, đồng bộ hồ sơ người dùng, role và quản lý tài khoản cho volunteer, manager, admin.

Event + Registration

Quản lý vòng đời sự kiện, đăng ký tham gia, duyệt participant, thống kê đăng ký và xác thực tham gia bằng QR.

Community + Chat

Cung cấp bài viết theo sự kiện, bình luận, reaction và hội thoại theo event để tăng gắn kết cộng đồng.

Notification + Analytics

Gửi web push notification, tổng hợp dashboard, export dữ liệu và hỗ trợ quản trị vận hành nền tảng.

Quick start

Authentication

Hầu hết endpoint yêu cầu Bearer token sau khi người dùng đăng nhập thành công.

Authorization: Bearer <access_token>
Content-Type: application/json

GET /api/v1/aggregated/events?pageNum=0&pageSize=10
Suggested flow
  • Đăng nhập và lấy access token.
  • Đọc danh sách sự kiện từ Aggregation hoặc Event service.
  • Gọi Registration service để đăng ký hoặc duyệt participant.
  • Dùng Notification và Chat cho luồng tương tác thời gian thực.

Architecture flow

Flow overview
Client → API Gateway → Domain services
Authorization Server cấp token cho protected APIs
Aggregation Service tổng hợp dữ liệu từ Event, User, Registration, Community
RabbitMQ và Redis hỗ trợ async workflow, cache và coordination
Developer notes
  • Nên ưu tiên `aggregated/events` cho màn hình danh sách sự kiện có dữ liệu ghép sẵn.
  • Dùng `registrations` cho toàn bộ participant lifecycle.
  • Dùng `analytics` và export API cho dashboard manager/admin.
  • Community và Chat nên đi kèm context xác thực và role của người dùng.
